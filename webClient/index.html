💡 Help & Documentation

Welcome to CRBot! Here is a quick guide on how to interact with it.

1. General

By default, you are connected to a simple banking database hosted in CockroachDB. You may use it as a playground. You may also select to experiment with an ECommerce database hosted in GCP CloudSQL by clicking on the gear icon on the upper right corner.

Or you may connect to your own postgres-complaint database by providing a connection URL in the same configuration screen. Custom connections as bound to a particular web browser session.

2. Natural Language Query

Type your query or instruction into the top text box in plain English or any other language. Click Translate Prompt to preview the generated SQL statement.

Example queries: "find all accounts with more than $5000", "give Mike $100", "allow Dary to browse client data", "Show all users created last week".

3. SQL Query

Review the SQL in the middle editor box. You can manually edit the statement or write custom queries from scratch. Click Execute SQL to run the command against your database.

4. 'I feel lucky' Mode

Clicking I feel lucky will automatically translate your natural language prompt and execute the resulting SQL in one step. Use this mode judiciously.

5. Selecting AI Model

By default, the application uses Gemini 3.6 Flash. You can change that in the configuration popup (gear icon).

6. Multi-turn conversations

CRBot remembers the last 5 prompt-response pairs and takes them into account before responding. If you want to reset chat histroy, open the History popup (clock icon) and click Clear Chat History.
