Datasets

Your questions address Datasets. A Dataset is defined as a set of 'tables' in a database and selected or configured in the dataset selection dialog that comes up when clicking the database badge in the header. Out of the box, you're offered various demo datasets hosted in different supported database types.

You may create your own dataset by connecting to your own database using the same dialog. The application supports several database systems including: portgreSQL, mySQL, Oracle, Microsoft SQL Server, Google BigQuery, Snowflake, Databricks, Amazon Redshift, MongoDB, and Google Sheets.

Your custom database connections are kept private and secure. If you do not log in, your custom connections are scoped to your current browser session only - nobody else can see or use them. If you log in, your connections are scoped to your account instead, so they follow you across sessions and devices, but are still never visible to any other user. Sensitive fields - passwords, service-account keys, private keys, access tokens - are encrypted at rest in the App's state database, and are never sent back to your browser once saved.

Datasets can be defined as groups of other datasets. Some such demo datasets are offered out of the box. In that case, the agent decides which dataset to contact for each user prompt.

Multi-Turn Conversations

The application remembers your last 3 turns. Each turn contains the prompt, the SQL it generated, the results that came back from the database, and any summarization. Use the ◀ / ▶ arrows in the NL prompt text box to step back and forward through previous turns. You may review past turns and delete them in the History Dialog.

User Authentication

If you log in, you will be able to carry your custom database connections and past translations history and preferences with you. Otherwise, custom database connections and past translation history stays with the browser session where they occurred.

User-Specified LLM API Keys

You may offer to use your own API key from Google, Anthropic or OpenAI for your own use ONLY of Datalect. Nobody else will see your keys or be able to use them. You may specify that key in the Preferences dialog. It will be much appreciated as it will reduce the cost of maintaining the Datalect.
