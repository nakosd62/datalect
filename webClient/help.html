Welcome to the Datalect Agent - it helps you talk to your Data in your Language.

Database Connections

By default, you're offered a playground database for each supported type of database. You may select which one to use by clicking the database badge in the header and using the dialog that will pop up. You may connect your own database using the same pop-up dialog (custom connections are private. i.e. session- or user-scoped).

Your custom connections are kept private and secure. If you do not log in, your custom connections are scoped to your current browser session only - nobody else can see or use them. If you log in, your connections are scoped to your account instead, so they follow you across sessions and devices, but are still never visible to any other user. Sensitive fields - passwords, service-account keys, private keys, access tokens - are encrypted at rest in the App's state database, and are never sent back to your browser once saved.

Natural Language Prompt

Type your query or instruction into the top text box in plain English or any other language. Click return when you're done, or shift-return for multi-line prompts.

SQL Query

Review the SQL in the SQL editor box. You can manually edit the statement or write custom queries from scratch. Click Execute to run the command. You can also configure the app to run the generated SQL automatically after each translation, from the database connection configuration popup.

Multi-turn Conversations

The application remembers your last 10 turns. Each turn contains the prompt, the SQL it generated, and the results that came back from the database. Use the ◀ / ▶ arrows in the NL prompt text box to step back and forward through previous turns. Reloading the app will erase past chat history/turns.

User Authentication

If you log in, you will be able to carry your custom database connections and past translations history with you. Otherwise, custom database connections and past translation history stays with the browser session where they occurred.
