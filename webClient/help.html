Welcome to yDyL - it helps you talk to your Data in your Language.

Quick Start

  1. Type a question in plain English into the top box (e.g. "What tables are in this database?") and hit Enter. You're automatically connected to a read-only demo database, so there's nothing to set up first.
  2. yDyL translates it into SQL and fills in the box below - review it (or edit it) before running anything.
  3. Click Execute to run the query and see the results at the bottom of the page.

Not sure what to ask? Click one of the example prompts above the SQL box to see the whole flow in action.

Database Connection

By default, you're connected to a shared playground database, which is read-only even though the application itself can handle DML and DDL. You can connect your own postgres-compliant database by clicking the database badge in the header and entering a connection string. Note: custom connections are user-scoped, so this feature is only available to logged-in users.

User Authentication

To use the full-featured application, sign in with Google. You can also use a restricted version of the app as an anonymous user - some features (custom database connections, translation history) need to be scoped to a specific user to be safe, so they're only available once you're signed in.

Natural Language Prompt

Type your query or instruction into the top text box in plain English or any other language. Click return when you're done, or shift-return for multi-line prompts.

SQL Query

Review the SQL in the SQL editor box. You can manually edit the statement or write custom queries from scratch. Click Execute to run the command. You can also configure the app to run the generated SQL automatically after each translation, from the database connection configuration popup.

Multi-turn Conversations

The application remembers your last 10 turns. Each turn contains the prompt, the SQL it generated, and the results that came back from the database. Use the ◀ / ▶ arrows in the NL prompt text box to step back and forward through previous turns. Reloading the app will erase past chat history/turns.
