Welcome to yDyL! It will help you talk to your Data in your Language. Here is a quick guide on how to interact with it.

User Authentication

To use the full-featured application, you must authenticate using Google. You may use a restricted version of the app as an anonymous user. This is because some features need to be scoped by user to be safe.

Database Connection

By default, you are connected to a playground database. The demo environment is read-only although the application can deal with DML and DDL as well. You may change the database connection by clicking on the database badge in the header and entering your own postgres-compliant database connection. Note: custom connections are user-scoped so this featrue si only available to logged on users.

Natural Language Prompt

Type your query or instruction into the top text box in plain English or any other language. Click return when you are done. You may use shift-return for multi-line prompts.

SQL Query

Review the SQL in the SQL editor box. You can manually edit the statement or write custom queries from scratch. Click Execute SQL to run the command. You may configure the application to run the SQL query automatically after successful prompt translation. To do that use the database connections configuration popup dialog.

Multi-turn Conversations

The application remembers your last 10 turns. Each turn contains the prompt, the SQL it generated, and the results that came back from the database. Use the ◀ / ▶ arrows in the NL prompt text box to step back and forward through previous turns. Reloading the app will erase past chat history/turns.
